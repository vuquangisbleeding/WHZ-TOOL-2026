INZ RUNNER

Cài INZ Runner

Bản cài này dành cho người được phát app. Máy cần có Google Chrome. Lần đầu mở, đơn và tài khoản đều trống. Bạn tự điền, rồi bấm Bắt đầu.

Username không có trong danh sách được phép thì app dừng và báo Không có trong whitelist. Chrome không mở. Nhờ người phát app thêm username đó.

Cách điền đơn, chạy và xử lý lỗi nằm trong HUONG_DAN_SU_DUNG.pdf, cùng thư mục với file này.

Chọn đúng file

MáyViệc cần làm
Mac chip Apple (M1, M2, M3, M4), macOS 11 trở lênMở thư mục Apple-Silicon, mở file .dmg, kéo INZ Runner vào Applications
Mac chip Intel, macOS 11 trở lênMở thư mục Intel, làm tương tự
Windows 10 hoặc 11, máy 64-bitBấm đúp INZ-Runner-Setup.exe

Trên Mac, bấm menu Apple, About This Mac. Dòng Chip ghi Apple M thì dùng Apple-Silicon. Dòng Chip ghi Intel thì dùng Intel.

Windows 32-bit không được hỗ trợ. File INZ-Runner-Setup.exe là bản 64-bit. Máy Windows chip ARM vẫn mở được file này.

Cài Google Chrome trước

App mở đúng Chrome đã cài trên máy.

  1. Vào https://www.google.com/chrome/.
  2. Tải bản Chrome đúng hệ điều hành và cài.
  3. Mở Chrome một lần, rồi có thể đóng.

Nếu app báo Không thấy Google Chrome, cài lại Chrome vào chỗ mặc định rồi mở app lại.

Cài trên Windows

  1. Bấm đúp INZ-Runner-Setup.exe.
  2. Nếu Windows hiện SmartScreen màu xanh: bấm More info, rồi Run anyway.
  3. Chọn thư mục cài nếu muốn, rồi bấm cài. Không cần quyền quản trị cả máy.
  4. Mở INZ Runner từ màn hình desktop hoặc menu Start.

File HUONG_DAN_SU_DUNG.pdf nằm cùng thư mục với INZ Runner.exe.

Lần đầu dùng

  1. Mở app. Tab Hồ sơ đang trống.
  2. Điền đơn theo HUONG_DAN_SU_DUNG.pdf. Ngày viết dạng 24 May, 1996. Giá trị chọn vẫn là chữ trên website, ví dụ Yes, No, Miss.
  3. Sang Cài đặt. Điền quốc gia chương trình đúng chữ trên thẻ quốc gia, ví dụ VIETNAM. Ô này phải giống ô quốc gia trong đơn.
  4. Dán danh sách proxy nếu tài khoản cần proxy. Mỗi dòng một proxy host:port:username:password.
  5. Thêm một dòng tài khoản: tên đăng nhập, mật khẩu, email. Tick Dùng proxy khi dòng đó phải lấy proxy trong danh sách phía trên.
  6. Autocaptcha API key, bot token và chat ID nằm trên whitelist. Sửa trên sheet. App không có ô để nhập ba giá trị này. Thiếu một giá trị thì lần chạy dừng.
  7. Bấm Lưu hồ sơ và Lưu cài đặt.
  8. Sang tab Chạy, bấm Bắt đầu khi bạn sẵn sàng chờ thẻ quốc gia OPEN.

App dừng trước lúc nhập số thẻ. Nút Mở trang thanh toán mở trình duyệt để bạn tự trả.

Dữ liệu nằm ở đâu

  • Windows: %APPDATA%\inz-puppeteer-multi-tab, thường là C:\Users\<tên bạn>\AppData\Roaming\inz-puppeteer-multi-tab
  • Mac: ~/Library/Application Support/inz-puppeteer-multi-tab

Trong đó có đơn, tài khoản, file cài đặt và thư mục logs. Xóa thư mục này là xóa dữ liệu đã nhập trên máy đó.

Gỡ app

Windows: Settings, Apps, chọn INZ Runner, Uninstall. Thư mục dữ liệu ở trên vẫn còn cho đến khi bạn tự xóa.

Mac: kéo INZ Runner từ Applications vào Trash.
