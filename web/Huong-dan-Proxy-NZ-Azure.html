Hướng dẫn tạo proxy New Zealand trên Azure

Tải file nz-proxy-azure.sh

1. Đăng ký tài khoản Azure

  1. Vào azure.microsoft.com.
  2. Bấm Pay as you go.
  3. Điền họ tên, email, số điện thoại và Country/Region theo địa chỉ thanh toán của bạn.
  4. Điền địa chỉ, xác minh số điện thoại và thêm thẻ thanh toán theo yêu cầu.
Lưu ý: Country/Region của tài khoản không quyết định vị trí proxy. Proxy vẫn được tạo tại New Zealand North.

2. Mở Cloud Shell

  1. Vào portal.azure.com và đăng nhập.
  2. Bấm biểu tượng >_ trên thanh trên cùng.
  3. Chọn Bash và đợi Cloud Shell mở xong.
  4. Nếu chưa tải file, bấm tải nz-proxy-azure.sh tại đây. Sau đó chọn Manage files → Upload và tải file lên Cloud Shell.

3. Chạy script tạo proxy

Trong Cloud Shell, chạy lệnh dưới đây. Ví dụ này tạo 21 proxy:

N_IPS=21 bash nz-proxy-azure.sh

Không ghi N_IPS thì mặc định tạo 10 proxy. Để mật khẩu trống, script sẽ tự tạo mật khẩu ngẫu nhiên.

Thời gian chạy: thường khoảng 5–8 phút. Không đóng Cloud Shell khi script đang chạy.

4. Lấy danh sách proxy

Khi chạy xong, script in ra IP, cổng HTTP, cổng SOCKS5, username và password. Danh sách cũng được lưu tại:

cat ~/nz-proxies.txt

Định dạng sử dụng là:

IP:PORT:USER:PASS
Quan trọng: Cloud Shell là tạm thời. Hãy copy danh sách và password ra nơi an toàn ngay.

5. Gửi proxy cho mình kiểm tra

Sau khi script chạy xong, hãy gửi nguyên danh sách proxy cho mình qua kênh trao đổi riêng để mình kiểm tra từng IP, cổng HTTP và SOCKS5.

cat ~/nz-proxies.txt
  1. Mở file hoặc copy toàn bộ kết quả hiện trên Cloud Shell.
  2. Gửi nguyên dòng theo định dạng IP:PORT:USER:PASS cho mình.
  3. Không đăng danh sách lên nhóm công khai hoặc gửi vào nơi nhiều người xem.
Mình sẽ kiểm tra: proxy có kết nối được không, IP có ra đúng New Zealand không và cả HTTP/SOCKS5 có hoạt động không.

6. Bảng giá thuê Azure tham khảo

Giá tính theo thời gian sử dụng. Bảng dưới quy đổi theo tỷ giá tham khảo 1 USD = 26.170đ, áp dụng cho máy tại Auckland/New Zealand và chưa gồm mọi khoản phát sinh.

Để ngừng tính phí: bấm Stop và chờ trạng thái Stopped (deallocated). Khi xong hẳn, xóa resource group để xóa cả VM, disk, IP và mạng.

Giá và tỷ giá có thể thay đổi. Hãy xem lại Cost Management trên Azure trước khi tạo máy.

7. Xóa khi không dùng nữa

Xóa resource group để xóa VM, disk, IP và mạng:

az group delete -n nz-proxy-rg --yes
Kiểm tra trước khi xóa: az resource list -o table. Chỉ xóa khi bạn chắc chắn không còn tài nguyên cần giữ.

Giá Azure và giao diện portal có thể thay đổi. Khi khác tài liệu, ưu tiên thông tin thực tế trên portal.
